# Cell by Cell — Unit 1 Exam Review (Koran)

Dashboard de repaso: Unit 1 Exam Review (Ch. 1–3) + Lab Activity 1, 2 y 3.

- 214 preguntas, 87 temas, 20 preguntas por día.
- Tipos: multiple choice, true/false, analyze the case, select all (con imágenes de tonicidad y cáncer de piel).
- Reglas: T/F incorrecta = 0 sin 2do intento. Otras: 1er fallo "Incorrect, one more try"; 2do intento correcto = ½; 2 fallos = 0 y muestra la contestación con explicación. Lo fallado vuelve al otro día con otra variante.
- Todo está dentro de `index.html` (banco e imágenes incluidos). No necesita otros archivos.
- El progreso se guarda en el teléfono de Koran (localStorage, clave `koran-unit1-review-v1`). No choca con el dashboard de Chapter 1.
